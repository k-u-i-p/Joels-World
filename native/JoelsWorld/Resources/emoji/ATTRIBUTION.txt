These 23 SVGs cover every emoji the app draws. They are a *fallback*: on a device whose
system font stack can draw colour emoji — every shipping iPhone — the platform glyph is used
and these files are never touched. They exist because the iOS Simulator runtimes ship a
stripped font set that renders every emoji as .notdef, which made verification screenshots
unreadable. See UI/EmojiImage.swift.

If this fallback ever becomes the primary rendering path, the CC-BY attribution above has to
appear somewhere the player can see it.
